# PaperLens · 论文透镜

一个在本机运行的 AI 论文阅读 WebUI，将文献管理、中文总结、双语阅读、图表浏览、划词问答和高亮笔记放在同一个工作空间中。

通过项目根目录的启动入口即可打开浏览器使用。Python 运行时和依赖安装在项目自己的 `envs/` 目录中，无需预先安装 Python、Conda、Node.js 或前端构建工具。

## 功能

| 模块 | 功能 |
| --- | --- |
| 文献库 | 拖放 PDF、选择文件或按本机路径导入；搜索标题、作者和论文内容 |
| 中文概览 | 配置模型后，后台生成中文标题、论文概要和阅读重点 |
| 阅读工作区 | 同时打开多份论文，通过顶部标签切换；保留各文档的阅读状态 |
| 双视图阅读 | 在 AI 重排与原版 PDF 之间切换，支持重排正文的字号调整 |
| 全文翻译 | 翻译正文和图注，保留原始图表内容；逐批显示译文并支持失败续译 |
| 段落续接 | 识别跨栏、跨页和图间续段，按完整段落翻译，在段落结束处显示一次译文 |
| 阅读助手 | 浏览目录及其中文翻译、图表及双语图注、高亮笔记和阅读重点 |
| 划词操作 | AI 解释、针对选段提问、翻译、高亮和复制 |
| 模型配置 | 添加多个 OpenAI API 兼容供应商，设置默认模型，并为不同任务分配模型 |

文献导入后会在后台解析和整理。尚未配置 AI 时，也可以查看本地提取的阅读内容与原版 PDF。“研究”页面目前保留为空白入口。

## 快速开始

### 1. 获取项目

克隆仓库，或通过 GitHub 的 **Code → Download ZIP** 下载后完整解压。将项目放在可以读写的普通文件夹中。

### 2. 启动

| 系统 | 根目录启动入口 | 验证状态 |
| --- | --- | --- |
| macOS · Apple Silicon | 双击 `启动论文透镜.command` | 已在 macOS arm64 环境验证 |
| macOS · Intel | 双击 `启动论文透镜.command` | 已提供对应运行时下载和启动流程，尚未实机验证 |
| Windows 10/11 · x64 | 双击 `启动论文透镜.bat` | 已准备独立运行时和依赖，尚未完成 Windows 实机验证 |

首次启动时，如果项目中没有可用的运行环境，启动程序会自动下载独立 Python、校验文件并安装依赖，需要能够访问 GitHub 和 Python 包索引。准备完成后，浏览器会自动打开：

```text
http://127.0.0.1:8765
```

后续启动会复用 `envs/` 中的环境。保持启动窗口运行；在窗口中按 `Ctrl+C` 可停止服务，单独关闭浏览器页面不会停止后台服务。

macOS 下载后的文件如果没有执行权限，可在项目目录中执行：

```sh
chmod +x "启动论文透镜.command"
./启动论文透镜.command
```

目前没有提供 Linux 启动入口。

### 3. 配置 AI 模型

点击右上角齿轮，进入“模型与参数设置”。

1. 添加供应商，填写供应商名称、访问 URL 和 API Key。访问 URL 使用供应商文档中的 OpenAI 兼容 API 地址。
2. 点击“获取模型列表”，选择默认模型；不提供模型列表接口的供应商也可以手动输入模型 ID。
3. 为论文总结、翻译、AI 问答和 AI 重排分别选择供应商。模块的模型 ID 留空时，继承所选供应商的默认模型。
4. 测试连接并保存设置。

AI 重排等任务要求模型能够返回符合约定的 JSON。程序会校验结果完整性，对无效或过长的结果进行有界重试和缩小范围恢复；最终无法恢复时保留原文，并显示可重试提示。针对 DeepSeek 等推理模型，包含思考内容与最终答案的分离处理。

### 4. 导入与阅读

1. 在文献库点击“添加文章”，拖入 PDF、选择文件，或填写本机文件的完整路径。
2. 等待后台解析；配置了相关模型后，会继续生成中文概览、目录与图注翻译，以及 AI 阅读顺序优化。
3. 点击文献卡片查看概览，再点击“进入文献阅读”。
4. 点击“全文翻译”生成双语内容；任务中断后可点击“继续翻译”补齐未完成部分。
5. 在正文中选中文字，即可进行解释、提问、翻译或高亮。

跨页和图间续段保留原始页码、图表及文本块定位，译文以完整段落为单位显示。布局算法更新后，旧文献打开时会后台升级结构；受影响的旧半段译文需要重新生成，匹配的完整译文、高亮和笔记会尽量复用。

## 本地存储与数据迁移

文献和阅读数据保存在项目根目录的 `data/` 中：

- `data/library.sqlite3`：文献索引、模型配置、译文、总结、高亮、笔记和阅读记录。
- `data/papers/`：导入的原始 PDF。

备份或迁移时，先停止服务，再复制整个 `data/` 目录到另一份项目中。运行环境位于 `envs/`，与用户数据分开保存。

原始 PDF 和阅读记录保存在本机。使用 AI 功能时，相关论文文本、选段或问题会发送至你配置的供应商；本地解析与原版 PDF 浏览不需要调用模型。API Key 保存在本机 SQLite 配置中，未额外加密，不应随源码或共享数据包公开。

## 运行环境与可迁移性

项目使用 Python Build Standalone 提供的 CPython 3.13.9，而非依赖本机解释器的普通虚拟环境。

- macOS 按处理器架构使用 `envs/python-macos-arm64/` 或 `envs/python-macos-x86_64/`。
- Windows 使用 `envs/python-windows-x86_64/`，必要的 C++ 运行库支持文件位于 `app/runtime-support/windows-x86_64/`。
- 同一系统、同一架构下，可以连同准备好的环境一起复制项目；跨系统时共享应用代码和数据，由目标系统准备对应的运行时。
- 完整环境准备好后，本地解析和阅读可离线运行；AI 功能是否需要联网取决于所配置的供应商。

## 项目结构

```text
paperlens/
├── README.md
├── 启动论文透镜.command       # macOS 启动入口
├── 启动论文透镜.bat           # Windows 启动入口
├── app/
│   ├── start.py                # 本机 HTTP 服务入口与默认参数
│   ├── bootstrap.py            # 项目内依赖安装
│   ├── launch.zsh / launch.ps1
│   ├── setup_runtime.zsh / setup_runtime.ps1
│   ├── requirements.txt
│   ├── requirements-windows.txt
│   ├── runtime-support/        # Windows 运行库及其授权文件
│   ├── backend/
│   │   ├── server.py           # HTTP API 与静态页面服务
│   │   ├── application.py      # 文献、翻译、缓存和后台任务
│   │   ├── storage.py          # SQLite 与原始 PDF 存储
│   │   ├── pdf_converter.py    # MarkItDown 转换
│   │   ├── pdf_engine.py       # 版面分析、图表定位与段落续接
│   │   └── ai_service.py       # 模型调用、结果校验与恢复
│   └── static/                 # 原生 HTML、CSS、JavaScript WebUI
├── envs/                       # 项目独立运行环境，不纳入 Git
└── data/                       # 用户数据，不纳入 Git
```

正文转换以 **MarkItDown** 为主，**PyMuPDF** 用于坐标、版面分析、图表区域定位及页面渲染，并提供转换失败时的回退。前端不需要安装 npm 依赖或执行构建。

## 开发与验证

服务默认参数统一位于 `app/start.py` 的 `DEFAULT_PARAMS` 中，也可以通过以下环境变量调整启动行为：

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `PAPERLENS_PORT` | `8765` | 本机服务端口 |
| `PAPERLENS_OPEN_BROWSER` | `1` | 设为 `0` 时不自动打开浏览器 |
| `PAPERLENS_DRYRUN` | `0` | 设为 `1` 时使用内存数据，并禁用 AI 网络请求及环境自动安装 |
| `PAPERLENS_SETUP_DRYRUN` | `0` | 设为 `1` 时，运行时安装脚本只输出准备计划 |

已有完整运行环境时，可使用 dryrun 模式预览。macOS：

```sh
PAPERLENS_DRYRUN=1 PAPERLENS_OPEN_BROWSER=0 ./启动论文透镜.command
```

Windows 命令提示符：

```bat
set "PAPERLENS_DRYRUN=1"
set "PAPERLENS_OPEN_BROWSER=0"
call "启动论文透镜.bat"
```

dryrun 不会加载正式文献库，退出后内存中的上传与修改会丢弃。尚未准备环境时，先以正常模式完成首次配置。

## 已知限制

- 当前主要面向包含文字层的学术 PDF，不包含 OCR；扫描件或文字转轮廓的页面可能无法提取正文。
- 单个导入文件上限为 60 MB，文档页数上限为 2000 页。
- 复杂图表、特殊排版和段落续接仍可能存在识别偏差，可随时切换到原版 PDF 核对。
- 翻译、总结与问答的质量和费用取决于供应商及模型，阅读结论需结合原文判断。
- “研究”页面尚未实现。

## GitHub 源码与离线分发

现有 `.gitignore` 已排除 `data/`、`envs/`、Python 缓存、系统文件及常规输出目录。源码仓库保留启动入口、`app/`、依赖清单和 Windows 运行库支持文件；用户下载源码后通过首次启动自动准备环境。

如需提供无需首次下载环境的离线版本，可按系统和架构分别打包源码与已准备好的对应 `envs/`，作为 GitHub Release 附件分发。发布包不应包含个人 `data/`、API Key 或未经授权分享的论文。
